# 🤖 Reinforcement Learning (RL) Projects

Bu depo (repository), Reinforcement Learning (Pekiştirmeli Öğrenme) alanında geliştirilen farklı algoritmaların ve projelerin uçtan uca örneklerini barındırır. Her bir klasör belirli bir RL algoritmasını (DQN, PPO, SAC, vb.) ve kullanım senaryosunu temsil etmektedir.

## 📂 Proje Yapısı

* **App1 (DQN)**: Deep Q-Network ile CartPole ortamının çözümü. Model izleme için MLFlow kullanılmıştır.
* **App2 (Double DQN & Dueling DQN)**: Pong oyunu üzerinde Double ve Dueling DQN uygulamaları.
* **App3 (PPO)**: Proximal Policy Optimization (Planlanıyor).
* **App4 (NEAT)**: NeuroEvolution of Augmenting Topologies (Planlanıyor).
* **App5 (SAC)**: Soft Actor-Critic (Planlanıyor).
* **App6 (AlphaZero & MuZero)**: İleri seviye RL algoritmaları (Planlanıyor).
* **App7- (MLFlow & Optuna)**: Model takibi ve hiperparametre optimizasyonu (Hastalık tahmini veri seti üzerinde denemeler).

## 🚀 Başlangıç

Sanal ortam (virtual environment) oluşturup bağımlılıkları yüklemek için:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r "App2 (Double DQN & Dueling DQN)\requirements.txt" # Örnek
```

Her bir projenin kendi klasörü içerisinde detaylı açıklamaları içeren `README.md` dosyaları bulunmaktadır.
